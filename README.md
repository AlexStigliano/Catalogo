# Stigliano Ferramenta — Sito vetrina

Sito vetrina one-page per **Stigliano Ferramenta**, Via Argine 600, Napoli — attività di famiglia dal 1869.

Ricostruito a partire dai contenuti del vecchio sito WordPress: storia, reparti, servizi, orari e contatti, in un design moderno, responsive e ottimizzato per smartphone.

## File

| File | Descrizione |
|------|-------------|
| **`index.html`** | Versione **autonoma** (CSS incorporato, zero dipendenze). Più veloce, si apre ovunque anche offline. È la versione consigliata da pubblicare. |
| **`index-tailwind.html`** | Stesso design ma con **Tailwind CSS via CDN**. Richiede connessione a internet per caricare Tailwind. |

Entrambi i file contengono gli stessi identici contenuti e la stessa grafica.

## Come pubblicarlo

Essendo un sito statico, puoi caricarlo ovunque:

- **GitHub Pages** — attiva Pages sul repository (Settings → Pages) puntando al branch. Rinomina il file scelto in `index.html` se usi la versione Tailwind.
- **Hosting classico / cPanel** — carica il file (rinominato `index.html`) nella cartella `public_html` via FTP.
- **Netlify / Vercel** — trascina la cartella nell'area di deploy.
